# FourPoint Management - Frontend

A responsive frontend page built with HTML, CSS, Bootstrap 5 and JavaScript.

## Built With

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Bootstrap Icons

## Features

- Responsive layout (mobile, tablet, desktop)
- Navbar with hamburger menu on mobile
- Profile card with user info
- 2x2 stats grid
- Foundation & Economy membership toggle (show/hide on click)
- Contact form with validation
- Toast notification on form submit
- WhatsApp FAB button
- Membership details modal

## How to Run

Just open `index.html` in your browser. No setup needed.
